Dino Crawler v1.8.0 Windows build
=================================
This package is based exactly on official release/tag v1.8.0, commit 92b471e65e49ff26572b83eac5e95fb0b625b0de.
The Electron wrapper launches the game maximized and packages the original HTML and audio assets, without changing gameplay or accessibility.
The build uses Electron 45.2.1 and electron-builder to create a portable x64 Windows executable.
The executable is unsigned; Windows SmartScreen may show an unknown publisher warning.
Mobile approved snapshot is kept separately at tag v1.8.0-mobile and is not part of this build.
